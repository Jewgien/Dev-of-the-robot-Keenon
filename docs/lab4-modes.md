## Цель работы

Освоить на практике все основные режимы работы робота-официанта Keenon DINERBOT T10 и получить навыки управления в условиях, приближённых к реальным сценариям.

---

## Режим 1 — Delivery Mode (Доставка)

Основной режим транспортировки предметов по заданному маршруту.

**Что делать:**
1. Зайди в главное меню приложения **«KEENON DINERBOT»**
2. Выбери **Delivery Mode**
3. Положи предметы на поднос
4. На экране нажми номера столиков — можно выбрать сразу несколько
5. Нажми кнопку **«Пуск»** — робот едет к первой точке
6. Чтобы остановиться в пути — нажми на экран → появится панель задач
7. Когда робот приедет — дождись, пока гость заберёт заказ → подтверди получение
8. Робот автоматически едет к следующей точке
9. После всех точек нажми **«Вернуться в исходную точку»**

---

## Режим 2 — Birthday Mode (Праздничная доставка)

Доставка с праздничной музыкой и анимацией на экране.

**Что делать:**
1. Нажми кнопку переключения режимов → выбери **Birthday Mode**
2. Откроется панель управления музыкой
3. Выбери трек из списка или включи автовоспроизведение
4. Нажми кнопку воспроизведения

---

## Режим 3 — Greetings Mode (Приветствие и сопровождение)

Робот встречает гостей у входа и провожает до нужного столика.

**Что делать:**
1. Переключись в **Greetings Mode**
2. Нажми **«Приветствие»** — появится маршрут обхода
3. Нажми **«Сопровождение»** — робот начнёт встречать гостей
4. По завершении нажми **«Вернуться в исходную точку»**

---

## Режим 4 — Dish Return Mode (Возврат посуды)

Робот собирает грязную посуду и везёт её в зону мытья.

**Что делать:**
1. Переключись в **Dish Return Mode**
2. Выбери действие:
   - **«Отправление»** — объедет столики и соберёт посуду
   - **«Вернуться в зону мытья посуды»** — сразу едет в зону мытья
3. Нажми нужную кнопку
4. Чтобы остановить — нажми на экран, робот вернётся в зону мытья
5. По завершении — **«Вернуться в исходную точку»**

---

## Режим 5 — Promotion Mode (Реклама)

Робот едет по маршруту и показывает рекламный контент на экране.

**Вариант А — Рекламная акция:**
1. Переключись в **Promotion Mode**
2. Нажми **«Рекламная акция»** — появится рекламный маршрут
3. Нажми **«Пуск»** — робот начнёт объезд с показом контента
4. По завершении — **«Вернуться в исходную точку»**

**Вариант Б — Путеводитель:**
1. В том же режиме нажми **«Руководство по покупкам»** (Shopping Guide)
2. Выбери целевую точку назначения
3. Нажми **«Пуск»** — робот проведёт клиента к нужному месту
