# Лабораторная работа №1

**Дисциплина:** Прикладные интеллектуальные системы  
**Тема:** План проекта: Разработка ПО для обеспечения экскурсий по центру компетенций на основе робота Keenon  
**Выполнили:** Кушнеревич Е. А., Шоева Е. Т. (группа ИИ-26)  
**Проверил:** Касьяник В. В.  

---

## Цель работы

Разработать поэтапный план создания учебного курса по работе с роботом Keenon DINERBOT T10, включающий анализ аппаратного устройства, проектирование настроек и карт, а также реализацию практических сценариев работы робота.

---

## Этапы проекта

### Этап 1 — Анализ (ЛР №2)
**Тема:** Анализ аппаратной части и характеристик робота  

- Изучение внешнего вида и компонентов робота
- Определение устройств отображения информации и их назначения
- Определение устройств ввода информации и типов датчиков
- Нахождение портов для сопряжения с роботом
- Изучение способов зарядки (кабель и зарядная станция)
- Первоначальный запуск и вход в приложение «KEENON DINERBOT»
- Проверка уровня заряда батареи: Settings → Charging

### Этап 2 — Проектирование (ЛР №3)
**Тема:** Проектирование настроек и карт маршрутов робота  

- Изучение базовых настроек (режимы, язык, скорость, время остановки)
- Изменение эмоции на сенсорном экране и заставки на рекламном экране
- Настройка звуковых параметров: громкость, голосовое оповещение, приветствие
- Изучение меню Scene Settings и существующих карт
- Создание новой карты через Mapping Tool
- Расстановка точек: Charging pile, Food outlet, Table

### Этап 3 — Реализация (ЛР №4)
**Тема:** Реализация практических режимов работы робота  

- Delivery Mode — доставка блюд
- Birthday Mode — праздничная доставка с музыкой
- Greetings Mode — встреча и сопровождение гостей
- Dish Return Mode — возврат посуды
- Promotion Mode — рекламный объезд
- Корректное завершение: возврат на зарядку, выключение

---

## Вывод

Разработан поэтапный план учебного курса по работе с роботом Keenon DINERBOT T10, охватывающий анализ аппаратуры, проектирование и практическую реализацию.
