## О проекте

**Dev-of-the-robot-Keenon** — это учебный курс, разработанный в рамках дисциплины **«Прикладные интеллектуальные системы»** на кафедре ИИТ Брестского государственного технического университета.

Курс решает задачу структурированного обучения работе с роботом: раньше для освоения Keenon DINERBOT T10 не существовало единого учебного материала на русском языке. Данный курс объединяет весь процесс — от изучения аппаратной части до практического запуска всех режимов — в последовательные лабораторные работы.

***

## Как построен курс

Обучение проходит через три последовательных этапа:

```
Знакомство с роботом
      │
      ▼
[1] Анализ (ЛР №2)
      Изучение аппаратной части, компонентов,
      датчиков, портов и способов зарядки
      │
      ▼
[2] Проектирование (ЛР №3)
      Настройка экранов, звука и интерфейса.
      Создание карты помещения с точками маршрутов
      │
      ▼
[3] Реализация (ЛР №4)
      Практическое освоение пяти режимов работы:
      Delivery / Birthday / Greetings / Dish Return / Promotion
      │
      ▼
Самостоятельная работа с роботом в реальных условиях
```

## Интерфейс и управление роботом

Взаимодействие с роботом ведётся через два экрана и приложение **KEENON DINERBOT**:

- **Сенсорный экран** — основной экран управления: запуск режимов, настройки, «лицо» с эмоцией
- **Рекламный экран** — дополнительный дисплей для контента и промо-материалов
- **Settings → Scene Settings** — управление картами маршрутов и точками
- **Settings → Charging** — мониторинг уровня заряда батареи

## Режимы работы робота

```
Приложение KEENON DINERBOT
      │
      ├──   Delivery Mode     — доставка блюд по заданным точкам
      │
      ├──   Birthday Mode     — праздничная доставка с музыкой и анимацией
      │
      ├──   Greetings Mode    — встреча и сопровождение гостей до столика
      │
      ├──   Dish Return Mode  — сбор и возврат посуды в зону мытья
      │
      └──   Promotion Mode    — рекламный объезд зала с показом контента
```

### Ключевые компоненты

- **Передний лидар** — лазерный дальномер для навигации и построения карты помещения
- **Датчик стереовидения** — трёхмерное восприятие пространства и обход препятствий
- **Модуль обнаружения лотка** — определяет наличие предметов на подносе
- **Контакт автоматической зарядки** — стыковка со станцией без участия оператора

## Использование курса

1. Начни с [`lab1-plan.md`](docs/lab1-plan.md) — изучи общий план и структуру курса
2. Выполни [`lab2-hardware.md`](docs/lab2-hardware.md) — найди и изучи все компоненты робота вживую
3. Выполни [`lab3-settings-maps.md`](docs/lab3-settings-maps.md) — настрой робота и создай карту помещения
4. Выполни [`lab4-modes.md`](docs/lab4-modes.md) — последовательно освой все пять режимов работы
5. После работы верни робота на зарядную станцию и выключи его

### Советы по созданию карты

- Проходи с роботом медленно, охватывая все проходы и зоны
- Убирай «шум» от людей через **Remove noise** после сканирования
- Ставь ограждения перед стеклянными стенами (`Glass wall`) — лидар их не видит
- Давай точкам уникальные и понятные названия (`Стол 1`, `Кухня`, `Зарядка`)

***

## Известные особенности

- PatchMatch Stereo (MVS) в режиме Delivery требует заранее созданной и активированной карты — без неё робот не знает маршрута
- Кириллица в названиях точек на карте поддерживается корректно; рекомендуется использовать короткие уникальные названия
- Стеклянные поверхности и открытые лестничные проёмы необходимо явно ограждать через `Glass wall` / `Staircase exit` — лидар их не распознаёт автоматически
