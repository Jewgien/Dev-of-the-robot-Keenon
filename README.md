## О проекте

Разработка учебного курса по работе с роботом **Keenon DINERBOT T10** в рамках дисциплины «Прикладные интеллектуальные системы».  
Курс включает анализ аппаратного устройства, проектирование настроек и карт, а также реализацию практических сценариев работы робота.
